# TRÉFLE: ALL IN — Prototipo base

## Motor
Godot 4.x

## Controles
- WASD: mover
- Mouse: apuntar
- Click izquierdo: lanzar cartas
- Q: Baraja Cinética
- E: Apuesta Maestra
- C: Polvo Cinético
- X: La Última Mano (cuando llegue al 100%)

## Cómo abrir
1. Instala Godot 4.x.
2. Abre Godot.
3. Importa la carpeta `Trefle_All_In`.
4. Abre `Main.tscn`.
5. Pulsa F6/F5.

## Estructura
- project.godot: configuración del proyecto y controles.
- Main.tscn: escena principal.
- scripts/main.gd: mundo, enemigos, cartas, habilidades y HUD.
- scripts/player.gd: movimiento y habilidades de Tréfle.
- scripts/enemy.gd: enemigos.
- assets/trefle_profile_reference.png: imagen de referencia del personaje.

Este prototipo es una base jugable 2D. Desde aquí se puede ampliar a arte real, animaciones, sonido, menús, campaña, inventario de cartas y multijugador.
